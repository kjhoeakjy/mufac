# 연합뉴스

![](photo.jpg)

> 연합뉴스에 안 나와

사랑 · 헤어진 사람의 이름은 못 치고 새벽 내내 속보만 넘기는 사람이, 끝내 소식 없음을 잘 지낸다는 뜻으로 받아들이는 중간 템포 시티팝.

## 이렇게 쓴 이유

연락할까 말까 망설이다 그 사람 소식을 엉뚱한 곳에서 찾아보는 기분은 거의 모든 사람이 겪어 봤기에 가장 넓게 닿는다. 자우림에게서 감정의 이유를 사소하게 쓰는 원리를 가져와 남의 나라 선거와 연예인 이사 소식으로 그리움을 비췄고, 술탄 오브 더 디스코에게서 감정을 말한 뒤 생활 사물로 김을 빼는 원리를 가져와 브릿지의 '보고 싶어서 그랬다' 뒤에 우산 챙기는 아웃트로를 놓았다. 잔나비의 고조 후 생활 말로 내려오기도 같은 자리에 겹쳤다. 같은 훅 '연합뉴스에 안 나와'가 처음엔 답답함이었다가 마지막 후렴에서 '아무 일 없는 하루는 연합뉴스에 안 나와'로 다시 읽혀 무소식이 희소식이라는 받아들임이 된다. 제목은 지정된 '연합뉴스' 한 단어를 그대로 두고 훅 첫머리에 세웠다.

참고한 곡

- 스물다섯, 스물하나 / 자우림: 감정의 이유를 사소하게 두어, 그리움을 연예인 이사 소식이나 남의 나라 선거 같은 시시한 기사 옆에 놓았다.
- 캐러밴 / 술탄 오브 더 디스코: 감정을 말한 바로 다음에 생활 감각으로 김을 빼는 원리로, '보고 싶어서 그랬다' 뒤에 우산 챙기는 말을 놓았다.
- 뜨거운 여름밤은 가고 남은 건 볼품없지만 / 잔나비: 고백 직전에 자기를 낮추고 가장 높은 순간 뒤에 생활 말로 내려오는 흐름을 브릿지와 아웃트로에 썼다.
- 불시 / 터치드: 후렴 글자 한두 개만 바꿔 화자의 변화를 보여 주는 방식으로 마지막 후렴의 두 줄을 바꿨다.
