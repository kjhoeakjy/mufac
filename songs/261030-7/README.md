# 노란

![](photo.jpg)

> 노란 불이야

어른 · 뛰면 탈 버스도 안 뛰고 사표는 임시보관함에 묵혀 두던 사람이, 노란 불 앞에서 처음으로 묻지 않고 건너려는 노래.

## 이렇게 쓴 이유

'노란 불이야'는 다섯 음절이고 끝이 모음이라 떼창으로 늘여 부르기 쉽습니다. 서야 할지 가야 할지 모르는 순간은 연애, 퇴사, 이사 누구에게나 있어서 가장 넓습니다. 조사 노트의 장판 초안은 집주인과 보증금으로 이어지는 상황극이라 버리고, 크라잉넛 '말달리자'처럼 외침 앞에 망설임을 쌓아 두는 원리와 극동아시아타이거즈처럼 지나간 사람을 펑크 템포로 담담하게 부르는 결을 가져왔습니다. 터치드 'Hi Bully'처럼 후렴 한 줄만 바꿔 화자의 변화를 보여 주려고, 마지막 후렴에서 '서는 거라면 자신 있어'를 '이번엔 안 물어'로 바꿨습니다. 제목은 지정된 '노란'을 그대로 쓰고, 훅 '노란 불이야'의 첫 낱말로 세웠습니다.

참고한 곡

- 말달리자 / 크라잉넛: 외침은 그 앞에 쌓아 둔 망설임이 있어야 터진다는 것, 그래서 후렴 전에 멈추는 장면들을 먼저 쌓았다.
- 비냄새 / 극동아시아타이거즈: 빠른 펑크 템포 위에서도 지나간 사람은 담담한 평서로 불러야 오래 남는다.
- Hi Bully / 터치드: 후렴의 한 줄만 바꿔 화자가 달라진 것을 보여 준다(서는 거라면 자신 있어 → 이번엔 안 물어).
- 뜨거운 여름밤은 가고 남은 건 볼품없지만 / 잔나비: 큰 감정어 옆에 손에 잡히는 사물 하나를 붙인다(부러움 옆의 무릎 흉).

조사 전체는 [research.md](research.md).

Verse 1 rides on picked eighth-note bass and one palm-muted power chord guitar over tight live drums, narrow talky melody.
