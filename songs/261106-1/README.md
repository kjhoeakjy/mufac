# 다 알면서

![](photo.jpg)

> 다 알면서

사랑 · 끝이 오는 걸 둘 다 느끼면서도 오늘 밤만은 손을 놓지 못하는 연인이 '우리'의 목소리로 부르는 중간 템포의 노래.

## 이렇게 쓴 이유

'다 알면서'는 끝날 걸 알면서도 계속해 본 적 있는 거의 모든 사람이 자기 일로 받는 말이고, 4음절에 모음으로 끝나 늘여 부르기 좋다. 극동아시아타이거즈처럼 마지막 후렴에서 한 줄을 뒤집는 원리를 가져와 '서로를 보내지 못해'를 '웃으며 서로를 보내'로 바꾸고, 자우림의 '미안해 널 미워해'처럼 모순(알면서 사랑한다)을 설명 없이 나란히 둔다. 이소라 '바람이 분다'처럼 훅은 짧게 두고 브릿지에서만 숨겨 둔 진심(보내지 못한 게 아니라 보내기 싫었다)을 처음 말한다. 제목은 후렴에서 그대로 불리는 끊긴 반말 문장이 가장 세게 박히고 듣는 사람이 뒷말을 자기 사정으로 채울 수 있어 후렴 문장 형태를 골랐다.

참고한 곡

- 바람이 분다 / 이소라: 느린 정서의 곡일수록 훅은 짧게, 반복은 적게 두고 마지막에 가장 크게 부른다.
- 다시, 다시 만나 / 극동아시아타이거즈: 마지막 후렴에서 핵심 줄 하나를 반대 뜻으로 바꿔 같은 훅을 다르게 들리게 한다.
- 미안해 널 미워해 / 자우림: 부딪치는 두 마음을 한 줄에 나란히 두고 설명하지 않으며, 한 곡의 어미 체계를 끝까지 지킨다.

조사 전체는 [research.md](research.md).
