# 다 녹아

> 봄 오면 다 녹아 다 녹아

아픔 · 올겨울이 통째로 망한 사람이 지금 꽁꽁 언 것도 결국 녹는다고 우기며 부르는 노래.

## 이렇게 쓴 이유

'봄 오면 다 녹아'는 망한 연애든 회사든 각자 지금 얼어붙은 것을 꽂아 넣을 수 있는 선언이라 다섯 후보 가운데 가장 넓다. 녹는다는 그림이 몽환적인 소리와 맞고, '눈사람도 원래 물이야'라는 능청 한 줄이 위로를 교훈이 아닌 농담으로 바꿔 준다. 잔나비의 원리를 주로 가져왔다. 핵심어 '다 녹아'를 두 번 겹치고, 고백 직전에 '아는 건 쥐뿔도 없는데'로 자기를 낮추고, 가장 높은 순간 뒤에는 '호빵이나 하나 사 먹자'라는 생활 말로 내려온다. 감정 이름 대신 '발 시려'처럼 몸의 감각을 쓴 것은 술탄오브더디스코의 김 빼기에서 가져왔다. 조사한 곡들에서 외치는 반말 문장 제목이 가장 세게 박히므로, 제목은 후렴에서 가장 많이 외치는 말인 '다 녹아'로 정했다.

참고한 곡

- 뜨거운 여름밤은 가고 남은 건 볼품없지만 / 잔나비: 후렴 핵심어를 겹치고, 고백 직전에 자기를 낮추는 한 줄을 놓고, 감정이 가장 높은 곳 뒤에는 생활 말로 내려온다.
- 캐러밴 / 술탄 오브 더 디스코: 비장해질 법한 대목 다음 줄에 몸의 감각을 놓아 김을 뺀다.
- 좋지 아니한가 / 크라잉넛: 위로는 설명이 아니라 우기기로 한다. 근거 없이 단정하는 한마디가 떼창이 된다.

조사 전체는 [research.md](research.md).
