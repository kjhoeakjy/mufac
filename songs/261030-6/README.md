# 이번 주말엔

> 이번 주말엔 내려갈까

어른 · 서울에 올라와 몇 년째 사는 사람이 퇴근길 택시에서 고향 쪽 소식을 듣고, 갈까 말까를 혼자 몇 번이고 되묻는다.

## 이렇게 쓴 이유

서울과 큰 도시에 올라와 사는 사람이 많아서 '내려갈까'는 가장 많은 사람이 실제로 중얼거려 본 말이고, 고향이 아니어도 각자의 '거기'를 넣어 부를 수 있다. 김현철의 「오랜만에」처럼 소리치지 않는 평서문 반복과 모음으로 열린 줄 끝이 시티팝의 느슨한 그루브에 맞고, 잔나비의 원리대로 가장 큰 진심(거기도 여기도 내 집 같지 않다) 뒤에 '택시는 아직 막히네'라는 생활 말로 내려온다. 화법은 이전 곡들의 말 걸기·외침과 겹치지 않게 혼잣말로 하고, 친구의 목소리는 따옴표로만 들였다. 제목은 후렴이 시작되는 끊긴 문장을 그대로 써서 부르는 순간 '그래서 갈 거야 말 거야'가 따라붙게 했고, 마지막 후렴에서 한 줄만 '내려갈게'로 바꿔 브릿지를 지나온 변화를 보여 준다.

참고한 곡

- 오랜만에 / 김현철: 도시적인 코드 위에 덤덤한 평서문을 반복하면 소리치지 않아도 그리움이 전해진다.
- 춘천 가는 기차 / 김현철: 이동 수단 하나가 떠나고 싶은 마음 전체를 대신할 수 있다.
- 광화문 연가 / 이문세: 장소를 직접 부르는 것만으로 시간을 되살리고, 감정어는 아껴 둔다.
- 좋은 사람 / 토이: 자기를 낮추는 화자가 중간 템포에서 망설임을 그대로 두면 듣는 사람이 자기 얘기로 받아들인다.
- 샴푸의 요정 / 빛과 소금: 베이스와 건반이 그루브를 이끌고 일상 사물 하나가 감정의 자리를 차지한다.

조사 전체는 [research.md](research.md).
