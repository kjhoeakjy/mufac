# 동그란

![](photo.jpg)

> 동그란 거 하나

어른 · 모난 말을 듣고 퇴근하는 사람이 주머니 속 도토리를 굴리며 혼자 버티는 하루.

## 이렇게 쓴 이유

'동그란 채로 가'는 '~한 채로'가 번역투라 빼고, 누구나 겪는 '모난 말을 들은 날'을 품을 수 있는 '동그란 거 하나'를 골랐다. 도토리 한 장면으로 줄거리를 짜지 않고 '작은 것 하나 쥐고 버티는 태도'로 넓혀 누구든 자기 회사, 자기 사람을 넣을 수 있게 했다. 한로로의 원리대로 비극이 아닌 시시한 사물(주머니 속 도토리)을 감정 앞에 두고, 마지막 후렴은 '들은 날'을 '한 날'로 한 글자만 바꿔 듣던 사람이 말한 사람이었다는 고백을 결론으로 삼았다. 자우림처럼 명사·조사에서 끊어 줄을 짧게 했고, 제목은 지정된 '동그란'을 훅 첫머리에 그대로 박았다.

참고한 곡

- 비틀비틀 짝짜꿍 / 한로로: 무거운 감정 한가운데 시시한 사물을 먼저 놓고, 마지막 후렴은 한 글자만 바꿔 결론을 낸다.
- 스물다섯, 스물하나 / 자우림: 명사·관형형에서 줄을 끊고 서술어를 생략해 짧은 줄로 여백을 만든다.
- 모기 / 극동아시아타이거즈: 하찮은 생활 사건에서 마음을 꺼내고, 2절은 1절의 틀을 지키며 시점만 옮긴다.

조사 전체는 [research.md](research.md).
