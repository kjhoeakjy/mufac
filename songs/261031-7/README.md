# 잇초케

![](photo.jpg)

> 잇초케 / 오늘은 져도 돼 / 잇초케 / 내가 다 봤어

아픔 · 시험, 면접, 경기, 고백 어디서든 진 날 먼저 웃어 버리는 사람에게 그 싸움을 다 지켜본 사람이 부르는 노래

## 이렇게 쓴 이유

'진 날'은 시험, 취업, 경기, 연애 어디에나 꽂히는 경험이라 가장 많은 사람이 자기 얘기로 받습니다. '져도 돼'는 메탈의 큰 소리와 부딪히는 허락의 말이라 의외의 힘이 있고, 슬픔을 키우지 않고 '내가 다 봤어'로 곁에 있다는 말만 남겨 담백합니다. 터치드의 후렴 낱말 바꾸기와 극동아시아타이거즈의 마지막 후렴 한 단어 뒤집기를 가져와 '오늘은→내일 또', '다 봤어→또 볼게'로 바꿨고, 브릿지의 '아무도 못 본 서러운 밤'이 처음 나와야 마지막 후렴의 '볼게'가 다르게 들리게 했습니다. 절은 자우림처럼 명사에서 끊고 서술어를 빼서 리프 위에 짧게 얹었습니다. 제목은 지정된 소리말 한 단어를 그대로 쓰고 후렴 첫 줄과 셋째 줄에 세웠습니다.

참고한 곡

- 다시, 다시 만나 / 극동아시아타이거즈: 마지막 후렴에서 핵심어 하나만 바꿔 같은 후렴이 다른 뜻으로 들리게 한다(오늘은→내일 또).
- Hi Bully / 터치드: 후렴 낱말을 한두 개만 바꿔 말하는 사람의 변화를 보여 준다(다 봤어→또 볼게).
- 일탈 / 자우림: 명사에서 끊고 서술어를 생략해 리프 위에 짧은 줄을 얹는다(풀린 주먹, 내려간 어깨).
- 좋지 아니한가 / 크라잉넛: 부정적인 장면을 쌓은 뒤 '그래도' 한 번으로 비틀어 우기듯 버틴다.
