# 버리긴 뭘 버려

> 버리긴 뭘 버려

어른 · 주변에서 이제 그만 접으라고 해도 서랍 속 기타와 공책을 버리지 못한 사람이, 열두 시가 넘으면 다시 꺼내 들며 부르는 노래.

## 이렇게 쓴 이유

'꿈 깨'라는 말은 거의 모든 사람이 들어 봤고, 그 말에 '버리긴 뭘 버려'로 받아치는 순간 각자 서랍 속 물건이 하나씩 떠오르기 때문에 가장 넓다.크라잉넛처럼 외칠 수 있는 한 덩이 말을 제목과 후렴에 두고, 잔나비처럼 후렴 직전에 '머리는 좀 빠졌지만'으로 자기를 낮춘 뒤 터뜨렸다. 터치드처럼 마지막 후렴은 두 줄만 바꿔 서랍 속에 넣어 두던 사람이 꺼내 트는 사람으로 바뀌게 했다. 제목은 후렴 문장 그대로 반말 반박으로 두어, 조사한 곡들에서 가장 많았던 반말 문장 제목 형태를 따랐다.

참고한 곡

- 말달리자 / 크라잉넛: 외칠 수 있는 한 덩이 말을 제목과 후렴에 그대로 두고 몇 번이고 되풀이한다.
- 뜨거운 여름밤은 가고 남은 건 볼품없지만 / 잔나비: 터뜨리기 직전에 자기를 낮추는 한 줄(머리는 좀 빠졌지만)을 놓아 후렴을 산다.
- Hi Bully / 터치드: 마지막 후렴은 두 줄만 바꿔 숨기던 화자가 꺼내는 화자로 바뀌게 한다.
- 별일 없이 산다 / 장기하와 얼굴들: 시시한 생활 말(월세, 통장, 철 들면 뭐 주는데)로 큰소리를 받쳐 능청을 만든다.

조사 전체는 [research.md](research.md).
