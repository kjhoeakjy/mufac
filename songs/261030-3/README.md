# 너는 삼 초면 잊는다며

![](photo.jpg)

> 너는 삼 초면 잊는다며

사랑 · 자기를 금붕어라 부르며 뭐든 잘 잊던 사람과 헤어진 뒤, 남은 쪽이 셋을 셀 때마다 다시 그 사람을 떠올리는 이야기다.

## 이렇게 쓴 이유

헤어진 사람은 금방 잊는 것 같은데 나만 남아 있다는 기분은 거의 모두가 겪어 봤고, '금붕어는 삼 초'라는 통념 덕분에 설명 없이 한 줄로 통하기 때문에 골랐다. 잔나비 「뜨거운 여름밤은 가고 남은 건 볼품없지만」처럼 후렴 첫 문장을 그대로 제목으로 삼아 부르는 순간 제목이 박히게 했고, 같은 제목 「금붕어」가 있는 한로로와 겹치지 않도록 단어 하나 대신 후렴 문장형을 택했다. 한로로 「0+0」과 터치드 「불시」처럼 마지막 후렴은 둘째 연의 한 줄과 메아리만 바꿨다. 셋을 세는 줄이 '잊으려는 시도'에서 '거짓말인 줄 알면서도 세는 것'으로 뜻이 바뀐다. 이전 곡이 빠른 스카 펑크와 중간 템포 시티팝이었으므로 이번에는 느린 인디록으로 했다. 화법은 우리와 혼잣말을 피해 너에게 말하기로 정했다.

참고한 곡

- 뜨거운 여름밤은 가고 남은 건 볼품없지만 / 잔나비: 후렴 첫 문장을 그대로 제목으로 삼고, 감정이 가장 높은 순간 뒤에는 생활 말로 내려온다(보고 싶다 → 아니면 말고, 우산은 챙겼니).
- 0+0 / 한로로: 마지막 후렴은 한 줄만 바꿔 같은 반복이 다른 뜻으로 들리게 한다.
- 스물다섯, 스물하나 / 자우림: 믿었던 말과 지금을 부딪혀 감정을 만든다. 삼 초라던 말이 거짓말인 줄 알면서 또 세는 마음이 그렇다.
- 불시 / 터치드: 후렴의 낱말을 조금만 바꿔 화자가 달라졌다는 것을 보여 주고, 반복은 짧게 끊는다.

조사 전체는 [research.md](research.md).

## 다른 후렴 후보

- 금붕어처럼 살자 (어른, 상사에게 혼난 말을 삼 초 만에 털고 다시 자리에 앉고 싶은 직장인이 혼자 중얼거린다.)
- 또 처음 보는 것처럼 (사랑, 오래 만나 무뎌진 연인이 서로를 매번 처음처럼 볼 수 있으면 좋겠다고 생각한다.)
- 한 바퀴만 더 돌고 (아픔, 같은 자리를 맴도는 하루를 보내는 사람이 그래도 한 바퀴만 더 돌아 보자며 다시 나선다.)
- 다 잊은 줄 알았는데 (아픔, 말 못 하고 보낸 사람이 아무렇지 않던 날 문득 떠오른 사람의 혼잣말이다.)
