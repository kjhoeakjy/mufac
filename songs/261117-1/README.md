# 멀리도 왔지

![](photo.jpg)

> 멀리도 왔지

어른 · 꿈꾼 곳에는 닿지 못했지만 같이 걸어온 사람들끼리 지나온 길을 돌아보며 웃는 밴드곡.

## 이렇게 쓴 이유

'멀리도 왔지'는 사회 초년생에게도, 오래된 친구 무리에게도, 혼자 버텨 온 사람에게도 자기 얘기로 들리는 말이라 다섯 후보 가운데 가장 넓습니다. 조사 노트가 고른 '열쇠는 두고 가자'는 생활 소품으로 장면을 세우는 가사였고, 아코디언 왈츠라 트로트 금지에도 걸려서 쓰지 않았습니다. 직전 두 곡이 '너에게'와 '혼잣말'이라 이번에는 '우리' 화법으로 갔고, 템포는 최근 R&B 76bpm과 겹치지 않게 중간 템포 밴드로 정했습니다. 크라잉넛 「좋지 아니한가」에서는 어긋난 장면을 늘어놓고 비트는 원리를, 잔나비에서는 고백 직전에 자기를 낮추는 줄('틀린 길로만 왔는데')을 가져왔습니다. 극동아시아타이거즈 「다시, 다시 만나」처럼 마지막 후렴에서 '아니어도'를 '보다 좋아'로 뒤집어, 같은 훅이 체념에서 긍정으로 들리게 했습니다. 제목은 훅을 그대로 쓴 후렴 문장형입니다. 셋이 함께 부르는 말이라 문장째 박히는 편이 가장 셉니다.

참고한 곡

- 좋지 아니한가 / 크라잉넛: 어긋난 장면을 늘어놓고 마지막에 비트는 원리를 '어디로 가는지 몰라 / 가는 건 잘하지 우리'의 자조로 가져왔다.
- 다시, 다시 만나 / 극동아시아타이거즈: 마지막 후렴에서 핵심어 하나를 뒤집는 방식을 따라 '꿈꾼 곳은 아니어도'를 '꿈꾼 곳보다 좋아'로 바꿨다.
- 스물다섯, 스물하나 / 자우림: 같은 문장 틀에 낱말 하나만 바꿔 쌓는 방식으로 '누구는 길을 바꾸고 / 누구는 멈춰 섰지'를 썼다.
- 뜨거운 여름밤은 가고 남은 건 볼품없지만 / 잔나비: 고백 직전에 자기를 낮추는 한 줄을 놓는 원리를 프리코러스 '틀린 길로만 왔는데'에 썼다.
