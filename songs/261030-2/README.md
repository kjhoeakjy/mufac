# 퇴근

> 퇴근이다 퇴근이야

어른 · 일 끝나는 시각만 기다린 모든 직장인이 문 앞에서 속으로 외치는 해방 선언

## 이렇게 쓴 이유

「퇴근」이라는 정해진 제목을 후렴 첫머리에서 두 번 겹쳐 외치게 했다. 크라잉넛처럼 외칠 수 있는 한 덩이 말과 4·4 율격을 쓰고, 술탄 오브 더 디스코처럼 허세(아무도 날 못 잡아) 바로 뒤에 초라한 사실(내일 또 오긴 와도)을 놓아 웃음을 만들었다.후렴은 줄마다 14음절에 맞추고 긴 음은 아·야·오로 끝내 꺾기와 떼창이 쉽게 했다. 제목은 지정어 그대로인 단어 하나라서 듣는 사람마다 자기 회사, 자기 시계를 떠올릴 수 있다.

참고한 곡

- 말달리자 / 크라잉넛: 제목 한 덩이 말을 4·4 율격으로 연달아 외치게 해서 떼창 후렴을 만든다.
- 요술왕자 / 술탄 오브 더 디스코: 허세를 크게 세운 바로 다음 줄에 초라한 사실을 놓아 김을 빼고 웃긴다.
- 일탈 / 자우림: 지루한 일상에 대한 짜증을 중심에 두고, 행동 몇 개로 태도를 보여 준다.

조사 전체는 [research.md](research.md).
