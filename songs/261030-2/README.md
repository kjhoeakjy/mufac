# 보호자 칸에 내 이름을 써요

> 보호자 칸에 내 이름을 써요

어른 · 아빠 입원 수속 날, 접수대에서 처음으로 보호자 칸에 자기 이름을 쓰는 삼사십 대 자식이 부르는 노래.

## 이렇게 쓴 이유

가족사진의 명함 사진이나 신호등의 노란불처럼, 서류 한 칸이라는 사소한 사물 하나가 역할이 바뀌는 순간 전체를 끌고 가기 때문에 골랐습니다. 가정통신문에서는 내 이름이 위 칸, 아빠 이름이 아래 칸이었고 병원 서류에서는 그 자리가 뒤집힙니다. 이 구조를 '자리가 바뀌었어요'라는 한 줄로 놓아두고 설명은 하지 않았습니다. 제목은 질문이나 고백 자체가 이야기인 경우라서 후렴 문장을 그대로 썼습니다. '보호자'라는 단어는 후렴마다 나오기 때문에 단어 하나 제목의 규칙과 맞지 않았고, 문장 제목이 쇼츠 자막과 검색에서도 바로 읽힙니다. 아빠의 '괜찮다'를 내가 되받는 반전은 나는 반딧불에서, 조언하지 않고 누워 쉬게 하는 태도는 마음의 숲에서 원리로 가져왔습니다. 잔나비처럼 쉬운 낱말과 다듬지 않은 문장으로 쓰고, 브릿지에서 '칸이 이렇게 넓었었나요'라는 질문으로 아빠가 채우던 칸의 크기를 처음 실감하게 했습니다.

참고한 곡

- 가족사진 / 김진호: 명함 사진 같은 구체적인 사물 하나로 시작해, 담담하게 쌓다가 마지막에 터뜨린다.
- 나는 반딧불 / 황가람: 스스로를 낮추는 말을 뒤집어 위로로 바꾸듯, 아빠의 '괜찮다'를 내가 되받아 말하게 한다.
- 신호등 / 이무진: 노란불처럼 일상의 사물 하나에 어른이 되는 순간 전체를 담는다.
- 꿈꾸던 어른이 되었나요? / 머무르: 괜찮은 척하는 마음을 꺼내 놓고, 후렴에서 듣는 사람이 자기 이야기를 대답하게 만든다.
- 마음의 숲 / 조선힙합: 뭔가 더 하라고 조언하지 않고, 그냥 쉬라고 다독이는 말이 사오십 대까지 닿는다.
- 뜨거운 여름밤은 가고 남은 건 볼품없지만 / 잔나비: 다듬지 않은 쉬운 문장과 끝을 열어 두는 말투가 듣는 사람의 기억을 불러낸다.

조사 전체는 [research.md](research.md).

- 아빠 구두가 작아 보여요 (어른, 명절에 본가 현관에서 아빠 구두 옆에 자기 구두를 벗어 두다가, 아빠 구두가 더 작아 보인 날 부르는 노래.)
- 이번엔 내가 정류장에 있을게요 (사랑, 야자 끝나면 늘 버스 정류장에 서 있던 아빠를 떠올리며, 이제 아빠 퇴근을 마중 나가고 싶은 자식이 부르는 노래.)
