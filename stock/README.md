# 상한가 · 하한가 예측

매일 아침 국내주식(코스피·코스닥) 상한가·하한가 후보를 확률·근거와 함께 보여 준다. 투자 권유가 아니다.

화면: https://kjhoeakjy.github.io/mufac/stock/

## 하루 흐름

1. 평일 07:20(한국시간) GitHub Actions `상한가 예측` 워크플로가 돈다.
2. 수집(`stock.collect`, `stock.collect_text`): 네이버 금융 전 종목 일봉(2019~)·투자자별 순매수(2022~)·업종·테마·공시 제목(2014~)·뉴스 제목(2년), 야후 해외지수·환율, DART 전일 공시.
3. 학습·검증(`stock.run`): 230여 개 변수로 LightGBM 상한가·하한가 모델을 학습. 최근 12개월은 매달 그 이전 데이터로만 학습해 예측하는 워크포워드 검증으로 적중률과 확률 보정표를 만든다.
4. 리포트(`stock.report`): 전 종목 점수, 상위 후보의 근거(기여 변수), 뉴스·공시, Claude 뉴스 판독(호재·악재 한 줄)을 `docs/stock/latest.json`에 쓰고 커밋한다. 전날 예측은 실제 결과로 채점해 `history/`에 남긴다.
5. 08:30 전에 페이지가 갱신된다.

## 장중 실시간 레이더 (PC)

```
python stock/radar.py
```

표준 라이브러리만 쓰므로 설치가 필요 없다. 브라우저에 http://localhost:8787 이 열리고, 7초마다 네이버 시세로 상한가·하한가까지 남은 거리, 진입·이탈, 거래대금을 보여 준다. 아침 후보는 ★로 표시된다.

## 파일

| 파일 | 역할 |
|---|---|
| `common.py` | HTTP, 경로, 숫자 파싱 |
| `collect.py` | 시세·수급·업종·테마·해외지수·DART 수집 |
| `collect_text.py` | 공시·뉴스 제목 수집(증분 캐시) |
| `features.py` | 가격·거래량·수급·시장·업종·테마·달력 변수와 라벨 |
| `text_features.py` | 공시·뉴스 제목 키워드 변수 |
| `model.py` | LightGBM 학습, 워크포워드 검증, 등온 보정 |
| `report.py` | 당일 후보·근거·채점 JSON |
| `llm.py` | Claude 뉴스 판독 (ANTHROPIC_API_KEY 없으면 건너뜀) |
| `radar.py` | 장중 레이더(PC) |
| `../docs/stock/index.html` | 화면 |

수집 데이터는 `stock-data` 브랜치에 매일 덮어쓴다(저장소 본문에는 두지 않음). 수급·뉴스 캐시는 Actions 캐시에 둔다.

## 라벨과 한계

- 상한가 = 다음 거래일 종가 등락률 ≥ +29.5%, 하한가 = ≤ −29.5% (수정주가 오차 허용). 장중 터치만 한 경우는 별도.
- 상한가는 종목·일 단위 약 0.2%, 하한가는 0.02%의 드문 사건이라 대부분의 후보는 빗나간다. 화면의 '과거 이 구간 적중'이 실제 기대치다.
- 전일 종가·밤사이 해외시장까지만 반영한다. 장중 사건은 레이더로 본다.
- KRX 정보데이터시스템·KIND는 Actions에서 막혀 있어 유통주식수·시장경보 지정 내역은 아직 없다.
