# 쇼츠가 퍼지는 조건과 mufac 반영 (2026-11-01 조사)

## 조사한 조건

| 조건 | 내용 | mufac |
|---|---|---|
| 첫 1~3초 | 시청자는 약 2.6초 안에 넘길지 정함. 첫 화면에 글이나 움직임이 있어야 함 | 제목 카드 삭제, 가사는 0초부터, 전주 구간에는 후렴 한 줄 표시 |
| 길이 | 15~30초가 끝까지 보는 비율이 가장 높음. 60초 넘으면 완주율 급락 | short_seconds 30 |
| 완주율·반복 | 70% 이상이 끝까지 보면 더 넓게 노출. 끝이 처음으로 자연스럽게 이어지면 반복 재생 | 페이드 0.3/0.6초로 단축 |
| 자막 | 크고 대비 높은 글, 화면 가운데 75% 안. 아래 400px·오른쪽 단추 영역 피함 | 가사 y=1380, 제목 y=200 |
| 곡당 여러 편 | 한 곡의 다른 구간은 서로 다른 입구. 같은 영상 재업로드는 불리 | 도입·후렴·브릿지·엔딩 넷, 그림·제목 모두 다름 |
| 올리는 빈도 | 주 3편 이상, 가능하면 매일 같은 시각 | 공개 범위가 public이면 하루 한 편 예약 공개(18시) |
| 올리는 시각 | 평일 오후~저녁 | publish_hour 18 |
| 첫 48시간 | 새 쇼츠는 48시간 동안 시험 노출. 그 안에 댓글 답글 | 운영자가 직접 |
| 제목 | 짧고 검색어가 되는 말. 모바일에서 잘리지 않게 | 쇼츠마다 그 구간의 가사 한 줄 + #shorts |
| 해시태그 | 3~5개가 적당, 61개 이상이면 전부 무시. 제목 위에 3개 표시 | 설명란 15개, 앞 3개는 곡이 고른 넓은 말, 이어서 노래·음악·인공지능 고정 |
| 설명 첫 줄 | 검색어와 전체 곡 링크 | 전체 노래 링크 + 가사 한 줄 |
| 소리 | 쇼츠 사운드로 등록되면 남이 내 곡으로 영상을 만듦 | 유통사(DistroKid) 등록 필요, 코드 밖 |
| 관련 영상 | 쇼츠에서 본편으로 가는 링크 | API로 못 걺. YouTube Studio에서 직접 |

## 코드 밖에서 할 일

- 공개 전환 뒤 첫 1시간 안에 댓글 답글. 쇼츠 첫 댓글에 전체 곡 링크 고정.
- YouTube Studio에서 쇼츠의 "관련 영상"에 본편 연결.
- 유통사 등록으로 쇼츠 사운드 라이브러리에 올림.
- 채널 분석의 시청자 활동 시간대를 보고 publish_hour 조정.
